# Дизайн-система

Направление: спокойное современное ателье. Тёплый бумажный фон, графитовая навигация, бордовый рабочий акцент, Georgia для предметных заголовков и системный sans-serif для плотной операционной информации.

Компоненты используют прямые края, тонкие разделители и минимум контейнеров. Главный визуальный объект — образец ткани. Минимальная зона нажатия 44px. Все поля имеют связанный label, ошибки — `aria-describedby`, динамические результаты — семантические status/alert. Анимации отключаются через `prefers-reduced-motion`.
